1.2.2. Linear Pattern

num_of_data = 100
min_error, max_error = -5, 5
x_i, y_i = [], []
min_max_x = (-5, 5)
slope, intercept = 2,0

for i in range(num_of_data):         # range(x,y) takes x and y, where x is 0 by default. It creates iterationable lists between x (included) and y (NOT included)
    function_x = rand.uniform(min_max_x[0],min_max_x[1])
    function_y = slope * function_x + intercept
    x_i.append(function_x) # instead of rand.int which only generates whole numbers. This makes floats as well.
    y_i.append(function_y + rand.uniform(min_error, max_error))

Graphing residuals on Bargraphs are pretty inconsistent, as the bar graph’s y-value (frequency) changes extremely drastically, depending on how large the bins are for the plot.

Think of a dataset: [1,2,3,4,5,6,7] where these numbers represent the frequency of each 7 categories from right to left. If the bin is 1, then we get [28], which would equate to just a single large bar. tbh this isn’t a good example to visualize, so changing the bar on the src above is better. Anyways, this abstraction causes problems to visualization
